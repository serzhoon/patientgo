# Веб-приложение для записи пациентов на приём

Курсовая работа по дисциплине «Интернет-технологии».

**Тема:** Разработка веб-приложения для записи пациентов на приём.

---

## Описание

Веб-приложение позволяет пациентам записываться на приём к врачам, просматривать
и отменять свои записи, а сотрудникам регистратуры (администраторам) — видеть все
записи пациентов. Реализованы регистрация, вход по паролю и разграничение прав по ролям.

### Возможности

- Регистрация и вход по email и паролю.
- Две роли: **пациент** и **администратор (регистратура)**.
- Запись на приём с выбором врача, даты и времени.
- Защита от двойной записи: одно время у врача нельзя занять дважды.
- Просмотр и отмена записей.
- Администратор видит все записи всех пациентов.

## Быстрый запуск через Docker (рекомендуется)

Нужен установленный Docker.

```bash
docker compose up --build
```

После старта:

- API доступно на `http://localhost:3000/api`
- Проверка: открыть `http://localhost:3000/api/health` — должно вернуть `{"status":"ok"}`

База данных создаётся автоматически при первом запуске (вместе с врачами и
администратором — см. раздел «Данные для входа»).

Открыть фронтенд: запустить файл `frontend/index.html` в браузере.

---

## Запуск без Docker (вручную)

1. Установить MySQL и создать базу, выполнив `backend/db/schema.sql`.
2. В папке `backend` скопировать `.env.example` в `.env` и заполнить.
3. Установить зависимости и запустить:

```bash
cd backend
npm install
npm start
```

4. Открыть `frontend/index.html` в браузере.

## Данные для входа

База уже содержит администратора (создаётся автоматически из `schema.sql`):

- **Администратор:** `admin@clinic.ru` / `admin123`
- **Пациент:** зарегистрируйтесь через форму регистрации.

## API (основные маршруты)

| Метод  | Путь                          | Доступ    | Назначение              |
| ------ | ----------------------------- | --------- | ----------------------- |
| POST   | `/api/auth/register`          | все       | регистрация пациента    |
| POST   | `/api/auth/login`             | все       | вход                    |
| GET    | `/api/doctors`                | все       | список врачей           |
| POST   | `/api/doctors`                | админ     | добавить врача          |
| DELETE | `/api/doctors/:id`            | админ     | удалить врача           |
| POST   | `/api/appointments`           | авторизов.| создать запись          |
| GET    | `/api/appointments`           | авторизов.| список записей          |
| PATCH  | `/api/appointments/:id/cancel`| авторизов.| отменить запись         |
