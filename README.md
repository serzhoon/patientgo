##  Описание

Веб-приложение для записи пациентов на приём к врачам поликлиник.
Реализованы три роли пользователей с разными возможностями, выбор города
и поликлиники, учёт статусов приёма, поиск и сортировка записей.

### Роли и возможности

**Пациент**
- Регистрация с указанием ФИО, даты рождения, города и поликлиники.
- Запись на приём к врачам своей поликлиники.
- Выбор свободного времени (занятые слоты не показываются).
- Просмотр и отмена своих записей.

**Врач**
- Просмотр записей пациентов к себе (с симптомами/жалобами).
- Отметка «приём состоялся» или «пациент не явился».
- Поиск по ФИО или телефону пациента, сортировка по дате, фильтр по дню.

**Администратор (регистратура)**
- Просмотр всех записей всех пациентов (с симптомами и датой оформления).
- Поиск по ФИО или телефону, сортировка по дате.

##  Архитектура

Приложение состоит из трёх контейнеров Docker, развёрнутых на сервере SberCloud:

- **clinic-frontend** — веб-сервер Nginx: отдаёт файлы сайта и проксирует запросы `/api` на бэкенд (порт 80).
- **clinic-backend** — сервер на Node.js + Express: обрабатывает логику и запросы к базе (порт 3000).
- **clinic-mysql** — база данных MySQL: хранит пользователей, врачей, поликлиники и записи (порт 3306).

##  Запуск через Docker

Нужен установленный Docker. В корне проекта выполнить:

```bash
docker compose up --build -d
```

После старта:
- **Сайт:** `http://localhost` (порт 80)
- **API:** `http://localhost:3000/api`

База данных, таблицы, врачи, поликлиники и администратор создаются
автоматически при первом запуске из файла `backend/db/schema.sql`.

Остановить:

```bash
docker compose down
```

Полностью пересоздать базу (при изменении структуры):

```bash
docker compose down -v && docker compose up --build -d
```
